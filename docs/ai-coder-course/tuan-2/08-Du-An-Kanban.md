# 📋 Bài 8: Dự Án — Kanban Project Management Platform

> Xây dựng nền tảng quản lý dự án Kanban có thể "chat" được

---

## 1. Mục Tiêu
Tạo ứng dụng Kanban board với tính năng AI chat — cho phép quản lý tasks bằng ngôn ngữ tự nhiên.

## 2. Tính Năng
- 📋 Kanban board (To Do → In Progress → Done)
- 💬 Chat interface: "Tạo task mới: Implement login"
- 🔄 Drag & drop cards
- 👥 Assign members
- 📊 Dashboard thống kê

## 3. Tech Stack
- Frontend: React + TypeScript
- Backend: Node.js hoặc ASP.NET Core
- Database: PostgreSQL
- AI: LLM API cho chat interface

## 4. Workflow Agentic
```
Dùng Claude Code CLI:

1. /plan → Thiết kế kiến trúc
2. Implement backend API
3. Implement frontend UI  
4. Tích hợp AI chat
5. Viết tests
6. Deploy
```

## 5. Bài Học
- **CLI agent** xử lý full-stack project
- **MCP** kết nối với task database
- **Skills** tái sử dụng CRUD patterns
- **GSD workflow** đảm bảo chất lượng
